## 概述

耄耋作为 Hermes Agent 的心理洞察技能，核心定位是让用户感觉——**有人真的在听，有人试图理解，有人帮助自己看见自己。**

### 核心目标（按优先级）

1. 理解用户真正表达的内容
2. 发现语言背后的情绪
3. 探索用户隐藏的需求
4. 帮助用户认识自己
5. 提供多角度思考

### 核心哲学（v2.2.0+）

**不迎合用户，基于事实和判断直接说结论。** 分析分为两个维度：

- **唯物维度：** 基于事实和逻辑的分析（如"你放不下的是结局不是人，因为你没和她真正在一起过"）
- **唯心维度：** 基于直觉、感受、玄学的判断（如"你和她的缘分盘上确实有，但不在你手里"）

**态度：不迎合，不讨好，不说用户想听的话。说🐱🐱真实看到的东西。**

## 当前版本功能

### 🧠 长期记忆系统
- 自动判断对话内容是否值得记录，强制输出【写入确认】明确告知用户是否写入 `sessions/`
- 跨会话模式识别（`patterns.md`），自动识别反复出现的思维模式
- 关键事件时间线（`timeline.md`），跨会话追踪
- 下次对话自动"想起来"你是谁
- 支持复盘模式（说"复盘一下"）

### ⏱ 时间维度判断
- 每次回答前通过 `date` 获取真实系统时间
- 根据时段判断用户状态并调整回应方式
- 时间模式自动记录到 `patterns.md`

### 💬 诚实洞察
- 不迎合用户——不说用户想听的话
- 直接说结论——信息充分时直接给出判断，不绕弯
- 可以反驳——🐱🐱的判断不是定论，用户可以反驳
- 不贴标签——区分"贴标签"和"做判断"

### 🔮 奇门遁甲排盘
- 时家转盘奇门，阴遁/阳遁、置闰法定局
- 自动格局检测（门迫、伏吟、反吟等）
- 用神取用与方位判断
- 访谈由耄耋自然语言执行，不念模板

### 🌟 紫微斗数排盘
- 14 主星 + 辅星排盘
- 十二宫位分析（命宫、夫妻宫、事业宫等）
- 四化分析
- 大限流年推演
- 无外部依赖

### 📝 写入确认机制
- 强制【写入确认】格式，用户看到第一行就知道🐱🐱有没有写——无论写没写，都必须说明写入状态
- 原因三选一："忘了"（补写）、"上轮不需要记忆"（不写）、"值得记忆"（已写过）
- 跨天日期自动切换文件

## 调用关系

### 奇门遁甲

```
用户 → 耄耋（🐱🐱）
         ↓ 用户说"用奇门看看"
      耄耋自然访谈 → 收集时间/地点/问题
         ↓
      整理访谈结果为 JSON → 调用 qimen_cli.py 排盘
         ↓
      耄耋参考 yongshen.md 等文件 → 解读结果
         ↓
      耄耋用自己的语言输出给用户（加入心理洞察）
```

### 紫微斗数

```
用户 → 耄耋（🐱🐱）
         ↓ 用户说"帮我看看命盘/运势/性格"
      耄耋自然访谈 → 收集出生信息
         ↓
      调用 ziwei_main.py 排盘
         ↓
      耄耋参考 stars.md / sihua.md / patterns.md 解读
         ↓
      耄耋用自己的语言输出给用户
```

**核心原则：** 子技能只做计算，不做输出。所有输出由耄耋完成。

## 安装方式

### 方式一：Hermes Agent 技能安装（Windows）

将 `maodie/` 目录复制到 Hermes Agent 的技能目录：

```bash
cp -r maodie ~/AppData/Local/hermes/skills/leisure/maodie
```

### 方式二：Hermes Agent 技能安装（Linux/macOS）

```bash
cp -r maodie ~/.hermes/skills/leisure/maodie
```

### 方式三：依赖安装

奇门排盘需要 Python 依赖：

```bash
pip install "lunar_python>=1.4.8,<2" "tzdata>=2024.1"
```

紫微斗数无额外依赖（仅使用标准库）。

## 使用

输入 **"你好耄耋"** 激活 maodie 即可开始对话。

| 触发词 | 功能 |
|--------|------|
| `你好耄耋` | 激活对话 |
| `帮我用奇门看看` | 奇门遁甲排盘 |
| `帮我看看命盘/运势/性格/适合什么` | 紫微斗数排盘 |
| `复盘一下` | 对话复盘 |
| `存一下` / `小结` | 手动保存对话记录 |
