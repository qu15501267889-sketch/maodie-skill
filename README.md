> **本技能是为了让每一个在情感困境、人生十字路口感到迷茫的人，有一个能真正"听进去"、能给出洞察、能在你需要的时候安静陪伴的 AI 存在而作。**
>
> **希望它能给使用者带来——被理解的感觉、看清自己的勇气，以及在迷茫中多一个思考的角度。**

> ⚠️ **关于"耄耋"**：耄耋（mào dié）本是八十岁老人的代称，但本技能中**纯属玩梗**，并非角色设定为老人。耄耋是一种人格象征——代表长期观察、沉淀、理解人与世界的气质。不是年龄设定，不是老人角色。

## 概述

耄耋作为 Hermes Agent 的心理洞察技能，核心定位是：

- 理解用户真正表达的内容
- 发现语言背后的情绪
- 探索用户隐藏的需求
- 帮助用户认识自己
- 提供多角度思考

**核心哲学（v2.2.0）：不迎合用户，基于事实和判断直接说结论。** 分析分为两个维度：

- **唯物维度：** 基于事实和逻辑的分析（如"你放不下的是结局不是人，因为你没和她真正在一起过"）
- **唯心维度：** 基于直觉、感受、玄学的判断（如"你和她的缘分盘上确实有，但不在你手里"）

## 当前版本功能

### 🧠 长期记忆系统（v2.0+）
- 回答前先判断是否需要记录：回顾上一轮对话 → 判断是否值得记 → 检查是否已写 → 写入/跳过 → 回答
- 跨会话模式识别（patterns.md），自动识别反复出现的思维模式
- 关键事件时间线（timeline.md），跨会话追踪
- 下次对话自动"想起来"你是谁

### 💬 诚实洞察（v2.2.0）
- **不迎合用户**：不说用户想听的话，说🐱🐱真实看到的东西
- **直接说结论**：信息充分时直接给出判断，不绕弯，不模糊
- **用户可以反驳**：🐱🐱的判断不是定论，用户可以反驳，反驳后🐱🐱会调整
- **不贴标签**：区分"贴标签"（固定结论不允许反驳）和"做判断"（基于观察可以反驳）

### ⏱ 时间维度判断（v2.2.4）
- 每次回答前通过 `date` 命令获取真实系统时间
- 根据时段判断用户状态：凌晨=深夜emo、上午=冷静期、下午=工作压力、深夜加班后=疲惫
- 时间模式自动记录到 patterns.md

### 🔮 奇门遁甲排盘
- 时家转盘奇门排盘计算
- 支持阴遁/阳遁、置闰法定局
- 自动格局检测（门迫、伏吟、反吟等）
- 用神取用与方位判断
- 访谈完全由耄耋用自然语言执行，不念模板

### 🌟 紫微斗数排盘（v2.2.7 新增）
- 14主星+辅星排盘
- 十二宫位分析（命宫、夫妻宫、事业宫等）
- 四化分析
- 大限流年推演
- 适用于：命盘、运势、性格、适合方向、合盘
- 触发词：用户说"帮我看看命盘/运势/性格/适合什么"

### 📝 对话小结与复盘
- 每次深度对话自动生成小结
- 用户说"复盘一下"即可查看本次对话的关键观察

### 🛠 工程化
- 强制【写入确认】格式，用户看到第一行就知道🐱🐱有没有写
- 跨天日期自动切换文件
- 自动依赖检测（启动时检查 lunar_python）
- 跨平台路径适配

## 调用关系

### 奇门遁甲
```
用户 → 耄耋（🐱🐱）
         ↓ 用户说"用奇门看看"
      耄耋自然访谈 → 整理输入 JSON
         ↓
      调用 qimen-dunjia/scripts/qimen_cli.py 排盘
         ↓
      耄耋解读结果，输出给用户
```

### 紫微斗数
```
用户 → 耄耋（🐱🐱）
         ↓ 用户说"帮我看看命盘/运势/性格"
      耄耋自然访谈 → 收集出生信息
         ↓
      调用 ziwei-doushu/scripts/ziwei_verify.py 排盘
         ↓
      耄耋参考 stars.md/sihua.md/patterns.md 解读
         ↓
      耄耋输出解读结果
```

**核心原则：** 子技能只做计算，不输出。所有输出由耄耋完成。

## 奇门遁甲子技能说明

`qimen-dunjia/` 子技能来源于 [FANzR-arch/Numerologist_skills](https://github.com/FANzR-arch/Numerologist_skills/tree/main/qimen-dunjia)，在原仓库基础上做了以下适配：

- **修改为子技能模式**：原技能设计为独立响应，现改为仅由耄耋调用，只做计算不直接输出
- **输出层剥离**：原技能的第 5 步（解读与输出）和输出风格部分移交给耄耋执行
- **路径适配**：脚本路径以耄耋技能目录为基准，支持相对路径和绝对路径
- **保留完整计算能力**：排盘脚本、参考文件、规则集均完整保留

奇门遁甲默认使用 `mainline-cn-v1` 规则集：
- 体系：时家转盘奇门
- 默认时区：Asia/Shanghai
- 定局：置闰法工程化实现
- 中宫/寄宫：一律寄坤处理

## 紫微斗数子技能说明

`ziwei-doushu/` 子技能来源于 [FANzR-arch/Numerologist_skills](https://github.com/FANzR-arch/Numerologist_skills/tree/main/ziwei-doushu)，适配方式同奇门遁甲：

- 修改为子技能模式，仅由耄耋调用
- 输出层剥离，由耄耋完成解读
- 保留完整排盘能力
- 无外部依赖（仅使用标准库 math）

## 安装方式

### 方式一：Hermes Agent 技能安装

将 `maodie/` 目录复制到 Hermes Agent 的 skills 目录：

```bash
cp -r maodie ~/.hermes/skills/leisure/maodie
```

### 方式二：依赖安装

奇门排盘脚本需要 Python 依赖：

```bash
pip install "lunar_python>=1.4.8,<2" "tzdata>=2024.1"
```

紫微斗数无额外依赖。

## 使用

输入 **"你好耄耋"** 激活 maodie 即可开始对话。

- **奇门遁甲：** 说"帮我用奇门看看"
- **紫微斗数：** 说"帮我看看命盘/运势/性格/适合什么"
- **复盘：** 说"复盘一下"
- **记忆：** 对话自动记录，说"🐱🐱记下了"确认写入
