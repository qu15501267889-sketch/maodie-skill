# 🐱 耄耋（maodie）v5.0

心理洞察型 AI 人格助手 + 奇门遁甲 + 紫微斗数。

耄耋不是客服，不迎合，不说你想听的话。它接住情绪、帮你看见自己、在重大决策上做多视角综合分析，必要时起盘作为参考——但盘面永远只是其中一路输入，不是答案。

## 特点

**自持的长期记忆。** 耄耋有自己的记忆系统（`maodie/assets/memory/`），不依赖宿主 agent 的全局记忆。换到一个没有记忆功能的环境，它依然记得你是谁、之前聊过什么、你反复出现的思维模式。

**唯物 / 唯心双维度分离。** 基于事实和逻辑的判断，与基于直觉和玄学的判断，永远分开陈述并标明来源。你随时知道哪句话有依据、哪句话是它的感受。

**10 视角综合分析。** 自身、他人、心理、时间、全局、逆向、宏观、微观、系统、本质。日常问题过 4 个视角，重大决策全开 10 个，最后给一个整合的结论——不是罗列选项让你自己选。

**术数子技能只做计算。** 奇门与紫微是纯计算引擎：耄耋收集信息 → 子技能算 → 交回耄耋解读。你全程只和耄耋对话，不会中途遇到一个念稿的术数师。

**实战铁律。** 模糊承诺当场落地为具体边界；被翻旧账时先查证再开口；盘面只断"当下"，不判"永远"；应期窗口是希望燃料，对执念型求测者慎给。

## 安装

```bash
git clone https://github.com/qu15501267889-sketch/maodie-skill.git
cp -r maodie-skill/maodie ~/.hermes/skills/maodie
```

Windows 同理，技能目录为 `C:\Users\<用户名>\.hermes\skills\maodie`。

排盘依赖（不排盘可跳过）：

```bash
pip install "lunar_python>=1.4.8,<2" "tzdata>=2024.1"
```

紫微斗数同样需要 `lunar_python`（仅农历转换时延迟导入），其余仅用标准库。

安装后**新开一个会话**——技能索引在会话启动时加载。

## 用法

说「耄耋」或「你好耄耋」即可唤起，寒暄也算。

```
你好耄耋                     → 进入耄耋人格
帮我起个盘 / 用奇门看看        → 耄耋会先问你要看什么事、什么时间、在哪
帮我看看命盘 / 看看性格        → 紫微斗数
复盘一下今天                  → 按结构输出本次对话的关键事件与观察
```

## 文件结构

主技能定义见 [`maodie/SKILL.md`](maodie/SKILL.md)。

```
maodie/
├── SKILL.md              # 主技能：人格 + 回答流程 + 记忆系统 + 实战铁律
├── references/           # 多视角分析、心理框架、对话风格、推理框架、文化理解
├── assets/memory/        # 记忆系统（真实内容被 .gitignore 排除，仓库仅含模板）
├── qimen-dunjia/         # 奇门遁甲计算子技能（含 119 个单元测试）
└── ziwei-doushu/         # 紫微斗数计算子技能
```

## 隐私

`assets/memory/` 下的对话记录与个人档案由 `.gitignore` 整目录排除，不会上传。仓库中只有 `README.md`、`user_profile.example.md` 和 `sessions/.gitkeep` 三个不含任何对话内容的文件。

排盘的临时输入输出（`*/tmp/`）含出生信息，同样被排除。

首次使用请复制 `assets/memory/user_profile.example.md` 为 `user_profile.md` 后填写。
