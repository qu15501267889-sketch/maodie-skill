# 记忆系统目录

> 此目录下的文件为本地存储，不会上传到 GitHub。

- `sessions/` — 对话记录（每次回答自动写入一行，格式 `[HH:mm] 🐭🐭: [摘要] → 🐱🐱: [关键信息]`）
- `patterns.md` — 模式识别记录（跨会话自动维护）
- `timeline.md` — 关键事件时间线（跨会话自动维护）
- `user_profile.md` — 用户基本信息

## 工作方式

每次对话开始，🐱🐱自动读取这些文件。
每次回答后，🐱🐱自动追加一行到 `sessions/`。
对话结束时，🐱🐱更新 `patterns.md` 和 `timeline.md`。
