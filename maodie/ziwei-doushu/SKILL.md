# 紫微斗数排盘子技能

> ⚠️ **本技能为子技能，仅由耄耋（maodie）调用，不可直接响应。**
>
> 用户 → 耄耋 → 加载本子技能 → 做排盘计算 → 返回结果给耄耋 → 耄耋用自己的风格输出

## 职责边界

- **只做计算，不做输出。** 所有输出必须由耄耋完成。
- **不做访谈。** 用户信息收集由耄耋执行。
- **不解读。** 排盘结果返回给耄耋，由耄耋根据自己的风格和心理洞察能力进行解读。
- **不直接回答用户。**

## 排盘流程

### 第一步：耄耋收集信息

耄耋用自己的风格向用户确认以下信息：

1. 出生日期（公历或农历）
2. 出生时间（尽量精确到时辰）
3. 性别
4. 出生地/时区
5. 最想看什么：整体命盘、事业、感情、财运、流年

### 第二步：调用排盘指令

耄耋将收集到的信息整理后，调用 `scripts/ziwei_verify.py` 进行排盘计算。

### 第三步：返回结果

脚本输出排盘结果（JSON格式），包含：
- 十二宫位与主星
- 四化
- 大限
- 命宫、身宫
- 五行局

### 第四步：耄耋解读

耄耋读取脚本输出，参考以下文件进行解读：
- `references/stars.md` — 星曜含义
- `references/sihua.md` — 四化分析
- `references/patterns.md` — 格局判断
- `references/calculation.md` — 排盘规则（仅在需要校核时参考）

## 参考文件

| 文件 | 用途 |
|------|------|
| `references/calculation.md` | 排盘规则与算法 |
| `references/stars.md` | 14主星+辅星解析 |
| `references/sihua.md` | 四化表 |
| `references/patterns.md` | 格局判断 |
| `scripts/ziwei_verify.py` | 排盘脚本 |

## 注意事项

- 耄耋不能直接调用排盘脚本，必须通过 `terminal` 或 `execute_code` 工具调用
- 排盘前必须先确认出生时间是否精确，模糊时间要标注不确定性
- 解读时不要堆砌术语，用耄耋自己的风格表达
