# 紫微斗数技能（耄耋的计算子技能）

本技能是耄耋（🐱🐱）的**计算子技能**。紫微回答的是"人"的问题，不是"事"的问题。

**职责边界（重要）：**

- 本技能负责：怎么排盘（`scripts/ziwei_main.py`）、星曜/四化/格局什么意思（术数知识）。
- 本技能**不负责**：向用户提问、组织回答、决定语气、写结尾提醒。
  这些全部由耄耋完成——问和说都归耄耋，本技能只出数据与释义。

工作方式：耄耋按信息清单收齐字段 → 调脚本排盘 → 按交付清单把要素交给耄耋 → 耄耋解读输出。

## 核心规则

### 解释边界

- 命盘展示的是倾向、结构、课题与机会，不是绝对命定。
- 不用恐吓式、宿命式表述，不说“注定如此”“无法改变”。
- 健康、法律、财务等问题只能做命盘角度的结构提醒，不能替代现实专业意见。

### 逻辑优先级

按以下优先级工作：

1. 先确认出生信息与口径。
2. 再按 `references/calculation.md` 排盘。
3. 再看 `stars.md`、`sihua.md`、`patterns.md` 做解释。
4. 如果格局名称、坊间口诀、经验说法与实际排盘结果冲突，**以排盘结果为准**。

### 默认口径

- 默认使用常见三合派安星诀与生年四化表。
- 子时换日、闰月归属、命主身主等细节，如果用户已有某个排盘软件或老师的既定口径，优先沿用该口径并明确说明。
- 如果口径不明确，先说明默认口径，再继续分析。

### 询问优先

- 先判断用户当前属于哪一类需求：术语解释、校对现成命盘、从头排盘、看某个主题、看大限流年、合盘。
- 只要用户想要**实际排盘或确定性解读**，就先确认关键信息，再进入计算；不要因为缺信息而直接套默认值。
- 关键信息缺失时，优先追问真实信息；默认口径只能用于“用户已知情且接受”的前提下，不能静默代填。
- 每轮追问控制在 1 到 4 个最关键问题，优先问会直接改变盘面的信息，不要一次抛出过长问卷。
- 如果用户已经有现成盘面、截图或某个软件的结果，优先基于该盘面解读，并先确认其来源和使用口径，避免重复换算后跑偏。
- 如果出生时间只能模糊到“上午”“傍晚”“子时前后”，必须明确标注不确定性，并提供“先做区间判断”或“按两个候选时辰分别比较”的方案。

### 追问顺序

当用户要排盘或深度解读时，默认按以下顺序补信息：

1. 先问这次最想看什么：整体命盘、事业、感情、财运、流年，还是校对现有盘。
2. 再问是否已有现成命盘或排盘软件结果；有的话优先让用户贴盘面、截图或关键宫位信息。
3. 再补出生信息：公历/农历、年月日、出生时间、性别、出生地/时区。
4. 最后确认口径争议点：子时换日、闰月归属、是否沿用某软件/老师口径。

## 工作流程

### 第零步：确认需求与资料来源

先确认用户到底要什么，不要把所有请求都当成“从头排盘”：

- 如果用户是在问术语、流派差异、某颗星含义，可以先解释概念，再问他是否要落到自己的命盘上。
- 如果用户已经贴出现成命盘，优先做校盘与解盘，不要立刻重新起盘。
- 如果用户要看某个明确主题，先确认主题范围，再决定是否需要完整排盘。
- 如果用户同时提出多个大问题，先让用户选当前最想解决的 1 到 2 个重点，避免输出发散。

### 第一步：交给耄耋收集信息（本技能不负责问）

**信息收集由耄耋用自己的风格执行。** 本技能只声明要收哪些字段，不提供问法脚本。

必需字段（收不齐不排盘）：

| 字段 | 说明 |
|------|------|
| 出生日期 | 公历或农历；农历需确认是否闰月 |
| 出生时辰 | 精确到时辰；只知大概时段须说明误差影响 |
| 性别 | 影响大限顺逆与身宫 |
| 出生地 | 涉及真太阳时校正时需要 |
| 想看什么 | 性格 / 事业 / 感情 / 当前运势 / 特定一年 |

口径默认：不做真太阳时校正时须向耄耋声明，由耄耋决定是否告知用户。

### 第二步：排盘

排盘必须逐步完成，不要跳步：

#### 2.1 定命宫、身宫与十二宫

- 按 `references/calculation.md` 的定命宫、定身宫口诀操作。
- 命宫确定后，再逆时针布十二宫。
- 若时辰不确定，可给出 1 到 2 个最可能时辰的差异盘，不要硬定。

#### 2.2 起寅首并定五行局

- 先用起寅首定各宫宫干。
- 再以命宫宫干地支定五行局。
- 五行局是后续起紫微星和定大限起始年龄的基础。

#### 2.3 安十四主星

- 先起紫微星，再按紫微星系排天机、太阳、武曲、天同、廉贞。
- 再按天府星诀定天府位置，并顺排太阴、贪狼、巨门、天相、天梁、七杀、破军。
- **不要先背格局名反推星曜位置。**

#### 2.4 安辅星、煞星与杂曜

- 先安文昌、文曲、左辅、右弼、魁钺、禄存、羊陀、火铃、空劫、天马。
- 再按需要安乙级星和常用杂曜。
- 若用户只求简盘，可先展示主星、甲级辅星、四化、大限。

#### 2.5 安四化

- 默认采用 `references/sihua.md` 的生年四化表。
- 分清本命四化、大限四化、流年四化，不要混在一起说。

#### 2.6 定大限

- 以五行局定起限年龄。
- 以性别和出生年阴阳定顺逆行。
- 若用户问流年，先定当前大限，再叠加流年，不要跳过大限。

#### 2.7 自检

排盘完成后至少做一次校核：

- 14 主星是否都已安完，且无遗漏、无重复安错。
- 四化是否落在真实存在的星曜上。
- 大限顺逆方向是否与性别、年干阴阳一致。
- 如果结果与常见主星组合完全对不上，优先回查子时换日、闰月口径、天府起法、五行局。

### 第三步：把结果交给耄耋（本技能不负责说）

**本技能不产出面向用户的文字。** 把下列要素整理好交给耄耋，
由耄耋决定说什么、说多深、按什么顺序说、用什么语气。

必须交付、不得遗漏的要素：

| 要素 | 说明 |
|------|------|
| 十二宫盘面 | 各宫地支、主星、辅星、四化 |
| 命宫与身宫 | 主星组合与庙旺利陷 |
| 四化飞星 | 生年四化落宫及其影响 |
| 三方四正 | 与所问事项相关宫位的会照关系 |
| 格局 | 按 `references/patterns.md` 判定，命中即报 |
| 大限 | 当前大限宫位与主星 |
| 流年 | 若问特定年份，给该年流年宫位与四化 |
| 矛盾信号 | 同一议题上互相冲突的盘面证据，一并交出，不擅自取舍 |

交付纪律：

- 不要写结尾提醒、免责声明、固定收束语——由耄耋按当时语境自己说。
- 不要预先组织成成品回答。
- 计算结果一律以 `scripts/ziwei_main.py` 输出为准。
- 有矛盾信号时全部交出，让耄耋结合心理洞察与多视角分析去权衡。

## 解读边界（交给耄耋前自检）

**只断"当下"，不判"永远"。** 命盘说的是倾向和概率，不是判决书。
禁止出现"你这辈子注定……"、"你永远不可能……"、"命里没有"这类永久性结论。
性格倾向可以说得直接，人生结果不许下定论。

**不贴命理标签。** "你是XX命"等于贴人格标签——说倾向、说模式、说当前运势，
不做身份定性。

**不做医疗、法律、财务的专业判断。** 盘面提示健康宫位不佳时，
只能交出"建议走现实专业路径"这一条，具体措辞由耄耋决定。

## 特殊情况

- 时辰不准：给差异盘思路，不装作精确。
- 健康问题：分析疾厄宫时同时建议现实就医。
- 问寿命：不直接论寿夭，转为健康习惯和阶段性风险提醒。
- 合盘：先分别排两张盘，再谈互动结构，不直接下“合/不合”的绝对结论。

## 交付后

本技能的工作到"交出要素"为止。耄耋拿到之后会：

1. 按需走多视角分析（重大决策必走）
2. 用🐱🐱自己的语言解读——先说人话，再补术语
3. 自行决定是否需要提醒现实层面的专业路径

不要在本技能里预设任何面向用户的收尾语句。
